# 智能群助手 (smart_group_assistant)

AstrBot 智能群管理插件，专为 QQ 群（OneBot V11 / Napcat）打造。自动识别群聊中的活动通知和会议通知，完成兴趣匹配、时间冲突检测、自动报名、日程管理、会前提醒和每日群聊整理。

---

## ✨ 功能概览

```
群消息
  ├─ 🤖 LLM 分类（活动 / 会议 / 其他）
  │
  ├─ 🎉 活动通知
  │   ├─ 兴趣关键词匹配
  │   ├─ 课程表时间冲突检测
  │   ├─ 自动提取报名方式
  │   ├─ 自动执行报名（发送个人信息私聊 / 申请加群）
  │   └─ 戳一戳 + 通知主人
  │
  ├─ 📋 会议通知
  │   ├─ 提取会议信息（名称/时间/地点/备注）
  │   ├─ 自动加入日程表（合并课程+会议）
  │   ├─ 通知主人
  │   └─ 会前提醒（戳一戳 + 消息）
  │
  └─ 📊 每日群聊整理（定时）
      ├─ 收集各群24h消息
      ├─ LLM 生成摘要（热点/通知/待办）
      └─ 发送给主人
```

## 📦 安装

### 前置要求

- AstrBot >= v4.16
- 已配置好的 QQ 消息平台（aiocqhttp / Napcat / Lagrange）
- 已配置的 LLM 提供商（推荐 DeepSeek）

### 安装步骤

1. **克隆或下载插件到插件目录**

```bash
cd AstrBot/data/plugins
git clone https://github.com/你的用户名/astrbot_plugin_smart_group_assistant.git
```

2. **安装依赖**

插件会在 AstrBot 加载时自动安装 `requirements.txt` 中的依赖。也可以手动安装：

```bash
pip install -r AstrBot/data/plugins/astrbot_plugin_smart_group_assistant/requirements.txt
```

3. **在 WebUI 中启用插件**

打开 AstrBot WebUI → 插件管理 → 找到「智能群助手」→ 点击启用。

4. **配置插件**（详见下方配置说明）

## ⚙️ 配置说明

所有配置项均可在 WebUI 插件详情页中可视化编辑。

### 必填配置

| 配置项 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `llm_provider` | 提供商选择 | LLM 提供商（推荐 DeepSeek） | 在下拉框中选择 |
| `owner_qq` | 字符串 | 主人 QQ 号，所有通知发送到此 | `123456789` |

### 监听配置

| 配置项 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| `group_whitelist` | 列表 | 监听的群号列表，留空则监听所有群 | `[]` |

### 主人报名信息

自动报名时，插件会将这些信息发送给活动发布者。

| 配置项 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| `owner_info.name` | 字符串 | 真实姓名 | `""` |
| `owner_info.gender` | 字符串 | 性别（男/女） | `""` |
| `owner_info.student_id` | 字符串 | 学号 | `""` |
| `owner_info.grade` | 字符串 | 年级（如 2024级） | `""` |
| `owner_info.class_name` | 字符串 | 班级（如 计算机科学2024级1班） | `""` |
| `owner_info.id_card` | 字符串 | 身份证号码 | `""` |

> 发送的私聊消息示例：
> ```
> 你好！我对你发布的「音乐节」活动很感兴趣，以下是我的报名信息：
> 
> 姓名：张三
> 性别：男
> 学号：2024001234
> 年级：2024级
> 班级：计算机科学2024级1班
> 身份证号：4201xxxxxxxxxxxxxx
> 
> 请问如何进一步完成报名？谢谢！
> ```

### 活动通知配置

| 配置项 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| `interest_keywords` | 列表 | 兴趣关键词（模糊匹配），命中任一即处理 | `[]` |
| `exact_match_keywords` | 列表 | 精确匹配短语（用于精确匹配特定活动） | `[]` |

> **关于兴趣匹配：** 如果两个关键词列表都为空，则默认匹配所有活动通知。

### 日程与课程表

| 配置项 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| `course_schedule` | JSON | 课程表，格式见下方 | `[]` |
| `ics_file_path` | 字符串 | .ics 日历文件路径（优先级高于JSON），留空则使用JSON | `""` |

**课程表 JSON 格式示例：**

```json
[
  {"name": "高等数学", "day": 1, "start_time": "08:00", "end_time": "09:35"},
  {"name": "线性代数", "day": 3, "start_time": "10:00", "end_time": "11:35"},
  {"name": "大学物理", "day": 5, "start_time": "14:00", "end_time": "15:35"}
]
```

> `day` 字段：1=周一, 2=周二, ..., 7=周日

### 会议配置

| 配置项 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| `reminder_minutes` | 整数 | 会前提醒提前量（分钟） | `15` |

### 每日整理配置

| 配置项 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| `summary_time` | 字符串 | 每日整理触发时间（HH:MM，24小时制） | `23:00` |
| `message_keep_hours` | 整数 | 群消息保留时长（小时） | `24` |

## 📖 使用指南

### 1. 日常运行（无需手动操作）

插件会**自动监听**白名单中所有群的消息，并进行分类和处理。用户无需发送任何指令。

### 2. 活动通知处理流程

当群里有人发布活动通知时（如音乐节、志愿活动等），机器人会：

1. ✅ 检查活动是否匹配你的**兴趣关键词**
2. ✅ 检查活动时间是否与**课程表**冲突
3. ✅ 从活动文本中**提取报名方式**（私聊发布者 / 加群等）
4. ✅ **自动执行报名**：发送个人信息私聊 / 申请加入活动群
5. ✅ **通知你**：戳一戳 + 汇总消息

### 3. 会议通知处理流程

当群里有人发布会议通知时（班会、项目讨论等），机器人会：

1. ✅ **提取会议信息**：名称、时间、地点、注意事项
2. ✅ **加入日程表**（与课程合并）
3. ✅ **通知你**：告知已将会议加入日程
4. ✅ **会前提醒**：会议开始前 N 分钟戳一戳 + 消息提醒

### 4. 每日群聊整理

每天配置的时间点（默认 23:00），机器人会：

1. 收集所有监听群的 24 小时内消息
2. 调用 LLM 生成整理报告
3. 发送给你，包含：
   - 📊 今日热点话题
   - 📢 重要通知摘要
   - 📋 待办事项

## 🔧 开发相关

### 适配平台

本插件仅适配 **aiocqhttp** 平台（OneBot V11 协议），在以下实现上测试通过：

- [Napcat](https://github.com/NapNeko/NapCatQQ)
- [Lagrange](https://github.com/LagrangeDev/Lagrange.Core)

### LLM 使用说明

插件会在以下场景调用 LLM：

| 场景 | 调用频率 | 消耗 |
|------|---------|------|
| 消息分类 | 每条群消息 | 低（简短分类 prompt） |
| 活动信息提取 | 仅匹配兴趣的活动 | 中 |
| 会议信息提取 | 仅在分类为会议时 | 中 |
| 每日整理摘要 | 每天 1 次/群 | 高（消息量大时） |

> **建议：** 使用 DeepSeek 等性价比高的模型，费用极低。不建议将 `interest_keywords` 留空，否则每条活动消息都会触发 LLM 提取。

### 数据存储

- **会议日程：** 存储在 `data/plugin_data/smart_group_assistant/meetings.json`
- **群消息缓存：** 仅保存在内存中，重启后清空（每日整理只依赖当天消息）
- **课程表：** 每次从配置/`.ics` 文件加载

## ❓ 常见问题

<details>
<summary><b>Q: 为什么机器人没有反应？</b></summary>

1. 检查 `owner_qq` 是否已配置
2. 检查 `llm_provider` 是否已选择且配置正确
3. 检查 `group_whitelist` 是否包含目标群（留空=所有群）
4. 检查 AstrBot 日志是否有 `[智能群助手]` 相关输出
</details>

<details>
<summary><b>Q: 活动没有被检测到？</b></summary>

1. 确认 `interest_keywords` 中包含相关的关键词
2. 或者将 `interest_keywords` 和 `exact_match_keywords` 都留空（匹配所有活动）
3. 检查 LLM 分类是否正确（查看日志中 `消息分类结果`）
</details>

<details>
<summary><b>Q: 报名私聊没有发送成功？</b></summary>

1. 确认活动文本中确实包含发布者的 QQ 号（LLM 需要能提取到）
2. 检查 Napcat/协议端是否已登录且正常运行
3. 部分协议端可能不支持主动发送私聊消息
</details>

<details>
<summary><b>Q: 加群操作失败了？</b></summary>

QQ 机器人主动加群受平台限制较大，大多数情况下需要手动加群。插件会在通知消息中说明哪些操作是自动完成的，哪些需要手动处理。
</details>
